- बनाना: Blender 4.2 (मुफ़्त) + VRM Add-on (MIT) — GitHub Actions पर अपने-आप render।
- आवाज़: Kokoro (Apache-2.0) या असली आवाज़।
- `proof/` — sandbox में बना पहला परीक्षण वीडियो।
